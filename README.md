Vulnerability Assessment & Secure Refactoring – Artemis Financial

Security-focused refactoring project for a web-based financial application to reduce vulnerabilities and improve data protection.

Highlights

Conducted a vulnerability assessment using OWASP best practices.

Implemented SHA-256 hashing for data integrity and SSL/TLS for secure communication.

Replaced insecure error handling with SLF4J structured logging.

Validated changes with functional testing and OWASP Dependency-Check to ensure no new CVEs were introduced.

Skills Demonstrated

Secure coding • Application hardening • Cryptography • Logging & monitoring • Static security testing • Risk mitigation
